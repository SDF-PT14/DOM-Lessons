# Welcome Student App
## Description
This is a simple web application that allow users to search for a user from an external API.
## Features
- A form to input name 
- Fetch data from the API
- Search for users by name
- Display the users details
- Error handling for invalid input and missing users 
## How to run the project
1. Clone the repository
2. Open the project folder 
3. Open the index.html file in your browser 
## Technologies Used 
- HTML
- Javascript
- CSS
- Fetch API(JSONplaceholder API)
